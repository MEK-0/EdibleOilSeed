Classification of Edible Oil Seeds Using Hybrid Deep Learning and Machine Learning Methods

Mahmut Esat Kolay · Murat Köklü

Selçuk University · Faculty of Technology
Department of Computer Engineering · Konya, Türkiye

Program: TÜBİTAK 2209-A University Students Research Projects Support Program

Project date: May 2026

Source note. Publication-stage figures on this page follow the manuscript summary supplied by the authors for this website. This checkout contains earlier project CSVs and reports, whose results differ; it does not contain the final manuscript, publication result CSVs, or VGG16–MLP OOF plots. These sources are kept separate below.

Abstract

This study examines classification of 10,111 images from six edible oil seed classes using fixed VGG16 and InceptionV3 deep feature representations. Five conventional machine-learning classifiers form ten hybrid combinations evaluated by stratified 10-fold cross-validation. The reported best combination, VGG16–MLP, achieved 99.8318% mean accuracy (SD 0.1716 percentage points) and 99.8340% macro F1 (SD 0.1687 percentage points), with 17 out-of-fold errors among 10,111 samples. The publication-stage evaluation reused saved features rather than repeating image preprocessing or CNN feature extraction.

1. Project Overview

Repeatable visual identification of agricultural products can support automated sorting, packaging, storage, and quality control, complementing purely manual inspection. This project studies machine-vision classification of edible oil seeds. It is a research evaluation, not a completed industrial sorting system.

2. Edible Oil Seed Dataset

The Edible Oil Seed Dataset (V2) contains 10,111 images across six classes. Groundnut is the largest class and white sesame the smallest. Stratification helps preserve this imbalanced class distribution across folds.

3. Image Acquisition and Preprocessing

In the original project, three-channel seed images were resized to 224 × 224 pixels, smoothed with a 3 × 3 Gaussian blur, converted to float32, and divided by 255 to normalize pixel values to [0,1]. These prepared images were passed to the CNN feature extractors.

Raw color image → resize 224 × 224 → Gaussian blur 3 × 3 → float32 → /255 → CNN features

Implementation note: src/preprocessing.py reads images with OpenCV, which uses BGR channel order by default; the checked-in code does not explicitly convert to RGB. The original acquisition camera and lighting setup are not established by this source inspection. No raw images were processed for this website.

4. Deep Feature Extraction

VGG16 and InceptionV3 use ImageNet-pretrained weights with include_top=False and Global Average Pooling. The CNN backbones act as fixed feature extractors; the machine-learning classifiers are fitted separately.

Table 2. Deep feature representations.
ModelInputPoolingFeature dimension
VGG16224 × 224 × 3Global average pooling512
InceptionV3224 × 224 × 3Global average pooling2048

Reported saved matrix shapes: VGG16, 10,111 × 512; InceptionV3, 10,111 × 2048. The publication-stage evaluation started from these saved matrices and did not fine-tune the CNN backbones.

6. Cross-Validation Protocol

The publication protocol specifies StratifiedKFold(n_splits=10, shuffle=True, random_state=42), with shared fold indices for all ten combinations: 100 fold-level evaluations. Accuracy, macro precision, macro recall, and macro F1 summarize performance. Standard deviations describe fold-to-fold variation, not confidence intervals.

Shared indices do not establish that independently saved VGG16 and InceptionV3 rows refer to the same original image. Labels alone cannot verify exact cross-matrix sample identity. The earlier repository scripts use cv=10 rather than the explicit shuffled splitter specified for publication.

8. Out-of-Fold Analysis

Out-of-fold (OOF) predictions are made for samples while they are held out from the corresponding training fold. The publication summary reports 10,094 correct predictions and 17 errors out of 10,111 images for VGG16–MLP, with 100% white sesame recall. The aggregate OOF correct fraction and the mean of fold accuracies are distinct summaries.

Best reported modelCorrect OOFIncorrect OOFWhite sesame recall
VGG16 + MLP10,094 / 10,11117 / 10,111100%

The VGG16–MLP OOF confusion matrix and row-normalized matrix are not available in this checkout. Existing SVM matrices were generated using a 20% holdout split, so they are not presented as OOF evidence. Low internal error does not demonstrate performance under external acquisition conditions or industrial readiness.

10. Limitations and Future Work

  • The final publication evaluation reused previously extracted features; raw images were not part of the final rerun.
  • Exact sample identity alignment between independently saved feature matrices cannot be established from labels alone.
  • No independent external test dataset was evaluated; changes in camera and illumination were not externally tested.
  • CNN backbones were not fine-tuned and classifier hyperparameter optimization was not performed in the publication evaluation.

Future work should preserve stable image identifiers during extraction, evaluate independent acquisition conditions, and compare tuned classifiers and fine-tuned backbones under a clearly separated evaluation protocol.
